# @nexus/contracts-order

Generated TypeScript client bindings for the Nexus Order Soroban contract.

This package is generated from the deployed (or locally built) Order contract using the Stellar CLI:

```bash
stellar contract bindings typescript --contract-id <ORDER_CONTRACT_ID> --output-dir packages/contracts/order --overwrite
```

Do not hand-edit generated files under `src/`. Regenerate them with `pnpm bindings` (see `scripts/generate-bindings.ts`) whenever the deployed contract changes.
